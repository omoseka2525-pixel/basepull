Airtable Importer alternative: what to use now that it's closed

Updated September 2026.

If you landed here, you probably opened Google Sheets™, went to Extensions, and found that Airtable Importer — the free add-on from Railsware that a lot of teams used to pull Airtable® data into Sheets — is marked [CLOSED] on the Marketplace. Railsware folded it into Coupler.io, its paid data-integration product. The other free listing, "AirTable 2 Google Sheet Sync", has not been updated in a long time and its recent reviews are people saying it no longer launches.

So you are looking for a replacement, and you have probably already noticed the annoying part: the free thing you were using was replaced by things that are not cheap. Below is what each option actually costs for the job Airtable Importer used to do.

First, decide how often you need it

This one question decides your bill. Every vendor sells a cheap tier that refreshes once a day and reserves hourly refresh for a much more expensive tier. If a daily refresh genuinely covers you, your options are inexpensive. If you need hourly — and most people mirroring a live base do — the price jumps by an order of magnitude with the big vendors.

Option 1: Coupler.io

The official successor to Airtable Importer, and a capable product with hundreds of sources. The free plan is limited to 100 rows per run and manual refreshes. Scheduled daily sync starts on Starter at $32/month with a 5,000-row cap per run. Hourly refresh is on the Pro plan at $259/month.

If you are running a real data stack with many sources, that is reasonable money. If all you wanted was one Airtable table in one sheet, it is a lot.

Option 2: Coefficient

Strong if you already use it for Salesforce or HubSpot and want Airtable alongside them. Free plan is manual only; Starter is $49/month for daily refresh with a 5,000-row import limit; hourly refresh is on Pro at $99 per user per month.

Option 3: Write it yourself in Apps Script

Free, and entirely reasonable if you write JavaScript. You create an Airtable personal access token, fetch the REST API, page through records, flatten the field types, write with setValues() and add a time-driven trigger. Budget an afternoon to build it and an ongoing trickle of maintenance for pagination, rate limits, new columns, expiring attachment URLs and triggers that silently stop. The full guide walks through this option in more detail.

Option 4: Basepull

Basepull is our add-on, and it exists precisely because of the gap above. It does one thing: mirror an Airtable table or view into a Sheets tab on a schedule — manual, hourly, every six hours or daily. It runs as Apps Script inside your own Google account and calls the Airtable API directly, so records go straight from Airtable into your spreadsheet and never pass through our servers.

The free plan gives you one manually-refreshed sync of up to 1,000 rows, which is enough to check it works on your real data. Pro is a flat $19/month — unlimited syncs, unlimited spreadsheets, hourly schedule included, up to 200,000 rows per sync.

Migrating from Airtable Importer

  1. Write down what you had. For each old import, note the base, table, view and the tab name it wrote to. Do this before you remove the old add-on.
  2. Create a read-only Airtable token. Scopes data.records:read and schema.bases:read, limited to the bases you sync. Airtable Importer used an older key format; you will need a new personal access token whichever tool you move to.
  3. Recreate each import as a sync pointing at the same tab name. Basepull replaces the tab's contents on every run, so any formulas, pivot tables or Looker Studio reports that reference that tab keep working untouched.
  4. Run each one once manually and compare the row count against Airtable before you trust it.
  5. Then set the schedule and remove the old add-on.

Common questions

Will my old imports keep working? No. A closed listing stops being installable and eventually stops running; plan the move rather than waiting for the day it breaks.

Is there still a free option? For manual refreshes, yes — CSV export costs nothing, and Basepull's free plan gives you one manual sync of up to 1,000 rows. For scheduled refreshes, free options have effectively disappeared; the honest answer is that somebody has to run the schedule and that costs something.

Do I have to give a tool access to my whole Airtable account? You should not have to. Personal access tokens are scoped to specific bases and can be read-only — use that.
